# NOVA Product Principles

## Quiet by default
The desktop disappears while you work. Motion communicates state rather than decorating the screen.

## Progressive disclosure
Common actions are obvious. Advanced controls remain available without dominating the interface.

## Truthful UI
A control exists only when the underlying operation exists. Unsupported capabilities explain themselves.

## Portable identity
A NOVA installation should eventually move between physical hardware and the Windows VM without forcing users to rebuild their environment.

## One system, two execution modes
Physical and virtual editions share the same userspace, configuration model and visual language.

## Safety without fear
Downloads, permissions and destructive operations require clear intent and understandable consequences.

## Performance is design
Blur, animation and background work are optional costs, not assumptions.

## Art direction
Graphite and warm near-white surfaces; restrained cyan for active state; amber for attention; red only for destructive/error state; large readable typography; subtle depth rather than neon gradients. The feeling should be precision equipment with a calm editorial surface.
